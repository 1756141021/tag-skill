# NAI 表达与权重

需要 NAI 语法、theme 或自然语言细节时读取；多人及文字分别按需查 [多人](nai-multi.md)和 [文字](nai-text.md)，不一次加载。

## 格式

默认以 Danbooru TAG 为主体。创作时用一句英文自然语言先说明动作、身体摆放、互动或空间关系，复杂多人最多两句；稳定视觉属性由 TAG 承担。用户明确要求纯 TAG 时不加动作句。

精修优先保留旧串的有效结构，不为加开场句而改写全部内容。NAI 的自然语言关系描述不等于切换成 Krea 的纯自然语言格式。

## 权重速查

- `{tag}` 加强，原稿记录每层约 x1.05；`{{tag}}` 约 x1.1025。
- `数值::tag::` 指定数值权重；`[tag]` 弱化，原稿记录每层约 x0.95。
- 语义相关词可以打包；核心突出，普通词保持原样。不要把角色分区问题交给高权重解决。
- 原稿记录过负数权重的定点抑制用法；需要时结合实际版本核对，不把经验效果视为保证。
- 不与 SD/A1111 的 `(tag:1.3)` 混用。跨平台转换语法，不直接照搬括号。

## Theme 的作用域

原技能的常规/SFW 首稿可主动选合适的现成 theme，优先颜色 theme，放在提示词前段适当加权。成人题材、其他平台不默认使用。

精修不自动新增、替换 theme 或画风；只有用户要求，或已确认的视觉概念确需时才调整。用户的原串和明确限制优先于创作默认值。

## 版本记录

原稿包含 V5/V4.5 的自然语言、提示词长度、多语言和角色定位经验。这里只保留其创作用途：用必要的关系句提高表达精度，复杂画面可补足信息，不因容量增加就堆词。

本次是结构整理，未重新核验现行模型、容量或界面。任务依赖具体版本功能时先核对对应版本文档；知识库手册是来源经验，不是实时产品规格。
