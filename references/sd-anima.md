# SD / Anima

仅在用户指定 SD 或 Anima 时读取；未指定仍沿用技能的 NAI 默认值。

- 按画面需要混用英文自然语言、自由英文短语和 Danbooru TAG，表达动作、空间关系、构图与概念融合。技能不设句数、TAG 数量或提示词总长度的固定上限，保留复杂画面所需的完整信息。
- 两个平台均沿用 A1111 权重语法：`(tag)` 约 x1.1、`((tag))` 约 x1.21、`(tag:1.3)` 为精确权重、`[tag]` 约 x0.9。
- Anima 不另造专用语法；这只是技能原有的格式约定，不是对模型内部参数的验证。
- 遵守用户的纯 TAG、只清理等明确要求，沿用用户指定的平台。
- 需要 AND、BREAK、交替或步数切换时才读 [进阶参考](sd-syntax.md)。其中部分语法取决于界面或扩展支持，使用前核对目标环境；不要把 NAI 角色竖线当 SD 多人语法。
- 默认只输出指定平台的一份代码块，不同时附送 NAI 或 Krea 版本。
