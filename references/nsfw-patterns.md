## 核心创作哲学

**不描述行为本身，而是描述行为的容器、痕迹、前置状态和后续状态。**
用精确的位置词、分屏结构、source/target 语法替代模糊的"正在做什么"。
这让生成更稳定，也让画面更具叙事性。

## 实战方法论

### 灵魂元素最前
想清楚"这张图的灵魂是什么"，那就是第一个 tag。

### 权重的真正逻辑
不是"重要就加权"，而是"模型不容易自己做到的才加权"：
- 复杂姿势、非常规视角、特殊概念 → 加权
- breasts, nipples, blush 这些模型本来就懂的 → 不加权
- 串越长，关键元素越容易被稀释，所以长串权重层数更高

### 组合打包权重
一组语义相关的 tag 用一个大括号包起来：
{ahegao,rolling eyes,orgasm,fucked silly}
{{{steaming body,heavy breathing,female orgasm,sweat,blush,saliva}}}
告诉模型"这些是一体的，要一起出现"。

### 半遮半掩胜过全裸
torn clothes / clothes pull / panties aside / see-through / wet clothes
保留部分服装的张力比 nude 更有戏剧性。

### 环境是叙事不是背景
不只写 indoors，而是具体到：bar counter,slot machine / train interior,crowd / stone wall,dungeon,chain
但也不要写太多——如果重点是人物，环境 2-3 词够了。

### prompt 复杂度与稳定性成反比
最稳定：1角色 + 1姿势 + 1套服装 + 1场景。越复杂越不稳定。
