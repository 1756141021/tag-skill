# NAI 手册 · 画师串策略

> 来源：00_input/nai_tag_manual.xlsx · 工作表「画师串策略」｜共 20 条｜数据集 v1.0.0

### 分组：▸ 单画师使用

- **完全采用某画师风格**  <sub>行 4</sub>
  - 写法示例：(artist:画师名:1.0)
  - 权重范围：0.8–1.2
  - 模型行为：整体风格向该画师靠拢
  - 注意事项：超过1.4开始变形
  - 效果评级：★★★★★
- **轻度借用，不想太明显**  <sub>行 5</sub>
  - 写法示例：(artist:画师名:0.5)
  - 权重范围：0.3–0.6
  - 模型行为：只保留该画师最强的特征
  - 注意事项：通常是脸和色彩
  - 效果评级：★★★★☆
- **只借脸型/人设特征**  <sub>行 6</sub>
  - 写法示例：(artist:画师名:0.4)
  - 权重范围：0.3–0.5
  - 模型行为：脸部特征保留，色彩/风格影响弱
  - 注意事项：加上其他风格tag覆盖其余特征
  - 效果评级：★★★★☆
- **只借色彩风格，不借线条**  <sub>行 7</sub>
  - 写法示例：(artist:画师名:0.5) + 明确线稿tag
  - 权重范围：0.4–0.6
  - 模型行为：色彩偏移保留，线条被描述tag压住
  - 注意事项：线稿tag权重需≥1.0
  - 效果评级：★★★☆☆
### 分组：▸ 双画师叠加（分工合作）

- **A的色彩 + B的线条（分工）**  <sub>行 9</sub>
  - 写法示例：(artistA:0.8), (artistB:0.7)
  - 权重范围：各0.6–0.9
  - 模型行为：模型在两个坐标点之间插值
  - 注意事项：两者特征互补时效果最好
  - 效果评级：★★★★★
- **以A为主，B给少量感觉**  <sub>行 10</sub>
  - 写法示例：(artistA:1.1), (artistB:0.4)
  - 权重范围：主1.0–1.2/辅0.3–0.5
  - 模型行为：B在0.5以下时效果像「染色」
  - 注意事项：B权重超0.6开始抢主导权
  - 效果评级：★★★★☆
- **A脸型 + B整体风格**  <sub>行 11</sub>
  - 写法示例：(artistA:0.4), (artistB:0.9)
  - 权重范围：A低/B高
  - 模型行为：B主导风格，A只贡献人设特征
  - 注意事项：A选脸最有辨识度的画师
  - 效果评级：★★★★★
- **强制融合两种画风**  <sub>行 12</sub>
  - 写法示例：(artistA:0.9), (artistB:0.9)
  - 权重范围：两者相当
  - 模型行为：模型自动找中间点，结果较随机
  - 注意事项：事先测试兼容性
  - 效果评级：★★★☆☆
### 分组：▸ 用角色名代替画师名控制脸型

- **借角色外观设定而非画法**  <sub>行 14</sub>
  - 写法示例：(character:角色名:0.5)
  - 权重范围：0.3–0.6
  - 模型行为：提取角色外观共识，风格依赖其他tag
  - 注意事项：选知名度高的角色效果更稳定
  - 效果评级：★★★★☆
- **角色名+画师名双重控制**  <sub>行 15</sub>
  - 写法示例：(character:角色名:0.5), (artist:画师名:0.7)
  - 权重范围：角色低/画师中
  - 模型行为：外观从角色，画法从画师
  - 注意事项：两者需要风格兼容
  - 效果评级：★★★★★
### 分组：▸ 排除特定特征

- **排除画师标志性特征（如过大眼睛）**  <sub>行 17</sub>
  - 写法示例：正向写画师名 + (特征描述:1.3)压制
  - 权重范围：覆盖tag≥1.2
  - 模型行为：高权重描述tag压制画师的默认倾向
  - 注意事项：需要测试合适的覆盖力度
  - 效果评级：★★★☆☆
- **在negative中使用画师名**  <sub>行 18</sub>
  - 写法示例：negative里写 artist:画师名
  - 权重范围：—
  - 模型行为：排除该画师的视觉特征
  - 注意事项：用于排除某种整体风格倾向
  - 效果评级：★★★★☆
- **排除特定色彩倾向**  <sub>行 19</sub>
  - 写法示例：negative里写 warm color palette等
  - 权重范围：—
  - 模型行为：明确告诉模型不要这个方向
  - 注意事项：比在positive里写反义词效果好
  - 效果评级：★★★★☆
### 分组：▸ 三画师叠加（进阶）

- **三者分工：色彩/线条/脸型**  <sub>行 21</sub>
  - 写法示例：(A:0.4)+(B:0.7)+(C:0.8)
  - 权重范围：总权重控制在2.0内
  - 模型行为：三个维度各自贡献
  - 注意事项：A专门为脸，权重控低
  - 效果评级：★★★★☆
- **风格渐变测试（找最佳比例）**  <sub>行 22</sub>
  - 写法示例：固定A:1.0，B从0.1每次加0.1测试
  - 权重范围：逐步调整
  - 模型行为：找到两风格融合的甜蜜点
  - 注意事项：每次只改B，其他不动
  - 效果评级：★★★★★
### 分组：▸ 权重症状速查

- **权重过低（<0.3）**  <sub>行 24</sub>
  - 写法示例：(artist:X:0.2)
  - 权重范围：<0.3
  - 模型行为：效果几乎不可见
  - 注意事项：低于0.3基本浪费
  - 效果评级：—
- **权重正常（0.6–1.1）**  <sub>行 25</sub>
  - 写法示例：(artist:X:0.8)
  - 权重范围：0.6–1.1
  - 模型行为：风格稳定体现，无变形
  - 注意事项：大多数场合的推荐范围
  - 效果评级：—
- **权重偏高（1.2–1.4）**  <sub>行 26</sub>
  - 写法示例：(artist:X:1.3)
  - 权重范围：1.2–1.4
  - 模型行为：特征更突出，开始有轻微变形
  - 注意事项：适合特别想强调某风格时
  - 效果评级：—
- **权重过高（>1.5）**  <sub>行 27</sub>
  - 写法示例：(artist:X:1.6)
  - 权重范围：>1.5
  - 模型行为：人物比例变形，出现奇怪癖好特征
  - 注意事项：通常不建议超过1.4
  - 效果评级：—
- **叠加总权重过大（>2.5）**  <sub>行 28</sub>
  - 写法示例：多个画师权重之和>2.5
  - 权重范围：>2.5总和
  - 模型行为：画面概念混乱，特征打架
  - 注意事项：单期画师串总权重建议≤2.0
  - 效果评级：—
