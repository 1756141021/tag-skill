# NAI 手册 · 色彩签名

> 来源：00_input/nai_tag_manual.xlsx · 工作表「色彩签名」｜共 35 条｜数据集 v1.0.0

### 分组：▸ 问一：整体色温（暖/冷）

- **warm color palette**  <sub>行 4</sub>
  - 中文含义：暖色调（通用）
  - 三问对应：问一
  - 识别方法：整体感觉有黄/橙/红成分
  - 常见组合：vivid / golden hue
- **cool color palette**  <sub>行 5</sub>
  - 中文含义：冷色调（通用）
  - 三问对应：问一
  - 识别方法：整体感觉有蓝/青/紫成分
  - 常见组合：desaturated / teal tones
- **golden hue**  <sub>行 6</sub>
  - 中文含义：金色色调
  - 三问对应：问一
  - 识别方法：整体偏琥珀/金黄
  - 常见组合：warm highlights / sepia
- **amber tones**  <sub>行 7</sub>
  - 中文含义：琥珀色调
  - 三问对应：问一
  - 识别方法：偏橙黄，像午后阳光
  - 常见组合：warm color palette
- **teal tones**  <sub>行 8</sub>
  - 中文含义：青蓝色调
  - 三问对应：问一
  - 识别方法：偏青绿蓝，冷静感
  - 常见组合：cool color palette / desaturated
- **sepia**  <sub>行 9</sub>
  - 中文含义：棕褐色调
  - 三问对应：问一
  - 识别方法：复古褪色的暖棕
  - 常见组合：faded / analog / retro
- **monochrome**  <sub>行 10</sub>
  - 中文含义：单色调
  - 三问对应：问一
  - 识别方法：只用黑白灰或单色渐变
  - 常见组合：ink / manga
- **duotone**  <sub>行 11</sub>
  - 中文含义：双色调
  - 三问对应：问一
  - 识别方法：只用两种颜色构成画面
  - 常见组合：retro print / risograph
### 分组：▸ 问二：饱和度（鲜艳/灰蒙）

- **vivid**  <sub>行 13</sub>
  - 中文含义：鲜艳（通用）
  - 三问对应：问二
  - 识别方法：颜色「跳」出来，很抢眼
  - 常见组合：saturated / rich colors
- **saturated**  <sub>行 14</sub>
  - 中文含义：高饱和
  - 三问对应：问二
  - 识别方法：颜色浓郁，纯度高
  - 常见组合：vivid / bold colors
- **rich colors**  <sub>行 15</sub>
  - 中文含义：浓郁色彩
  - 三问对应：问二
  - 识别方法：颜色厚实有重量感
  - 常见组合：oil painting / saturated
- **muted colors**  <sub>行 16</sub>
  - 中文含义：低饱和/灰蒙
  - 三问对应：问二
  - 识别方法：颜色像被加了灰，不鲜艳
  - 常见组合：desaturated / faded
- **desaturated**  <sub>行 17</sub>
  - 中文含义：去饱和
  - 三问对应：问二
  - 识别方法：接近灰色，颜色很淡
  - 常见组合：muted / washed out
- **faded**  <sub>行 18</sub>
  - 中文含义：褪色感
  - 三问对应：问二
  - 识别方法：像放久了的照片
  - 常见组合：analog / film grain / retro
- **washed out**  <sub>行 19</sub>
  - 中文含义：洗白感
  - 三问对应：问二
  - 识别方法：整体偏白/过曝感
  - 常见组合：faded / soft lighting
- **pastel colors**  <sub>行 20</sub>
  - 中文含义：马卡龙色调
  - 三问对应：问二
  - 识别方法：颜色浅淡柔和，像粉笔
  - 常见组合：soft / dreamy / cute
- **earthy tones**  <sub>行 21</sub>
  - 中文含义：大地色系
  - 三问对应：问二
  - 识别方法：棕、绿、米等自然色
  - 常见组合：painterly / nature themes
- **neon colors**  <sub>行 22</sub>
  - 中文含义：荧光色
  - 三问对应：问二
  - 识别方法：极度鲜艳，有发光感
  - 常见组合：cyberpunk / dark background
### 分组：▸ 问三：签名色写法（颜色偏移）

- **warm highlights, cool shadows**  <sub>行 24</sub>
  - 中文含义：暖高光冷阴影
  - 三问对应：问三
  - 识别方法：亮部偏黄，暗部偏蓝
  - 常见组合：最常见色温对比写法
- **warm light, magenta shadows**  <sub>行 25</sub>
  - 中文含义：暖光品红阴影
  - 三问对应：问三
  - 识别方法：阴影带品红/玫红
  - 常见组合：特定画师签名风格
- **warm light, purple shadows**  <sub>行 26</sub>
  - 中文含义：暖光紫色阴影
  - 三问对应：问三
  - 识别方法：阴影带紫调
  - 常见组合：幻想/少女向常见
- **cool light, warm shadows**  <sub>行 27</sub>
  - 中文含义：冷光暖阴影
  - 三问对应：问三
  - 识别方法：月光/夜晚场景
  - 常见组合：夜景/逆光场景
- **chromatic aberration in shadows**  <sub>行 28</sub>
  - 中文含义：阴影色差
  - 三问对应：问三
  - 识别方法：暗部有额外颜色信息
  - 常见组合：画面有「染色感」时
- **pink color grading**  <sub>行 29</sub>
  - 中文含义：粉色调色
  - 三问对应：问三
  - 识别方法：整体被粉调滤镜覆盖
  - 常见组合：少女感/梦幻感
- **teal color grading**  <sub>行 30</sub>
  - 中文含义：青色调色
  - 三问对应：问三
  - 识别方法：整体被青调滤镜覆盖
  - 常见组合：赛博/冷峻感
- **orange and teal**  <sub>行 31</sub>
  - 中文含义：橙青对比调色
  - 三问对应：问三
  - 识别方法：好莱坞大片式调色
  - 常见组合：电影感/CG感
- **split toning**  <sub>行 32</sub>
  - 中文含义：分离调色
  - 三问对应：问三
  - 识别方法：亮部/暗部各自不同颜色
  - 常见组合：时尚摄影感
### 分组：▸ 整体气质类（氛围tag）

- **dreamy**  <sub>行 34</sub>
  - 中文含义：梦幻感
  - 三问对应：—
  - 识别方法：柔焦、色彩柔和、有光晕
  - 常见组合：pastel / soft / glow
- **ethereal**  <sub>行 35</sub>
  - 中文含义：空灵感
  - 三问对应：—
  - 识别方法：高亮调，颜色淡，有透明感
  - 常见组合：white / light / airy
- **melancholic**  <sub>行 36</sub>
  - 中文含义：忧郁感
  - 三问对应：—
  - 识别方法：低饱和，偏冷，光线暗
  - 常见组合：desaturated / cool / low contrast
- **vibrant**  <sub>行 37</sub>
  - 中文含义：活力感
  - 三问对应：—
  - 识别方法：高饱和，高对比，明亮
  - 常见组合：vivid / high contrast
- **dark atmosphere**  <sub>行 38</sub>
  - 中文含义：暗黑氛围
  - 三问对应：—
  - 识别方法：整体低调，暗部大
  - 常见组合：deep shadows / low key
- **cinematic**  <sub>行 39</sub>
  - 中文含义：电影感
  - 三问对应：—
  - 识别方法：宽幅比例，调色有质感
  - 常见组合：film grain / color grading
- **retro**  <sub>行 40</sub>
  - 中文含义：复古感
  - 三问对应：—
  - 识别方法：颜色褪色，有年代感
  - 常见组合：faded / sepia / grain
- **gothic**  <sub>行 41</sub>
  - 中文含义：哥特感
  - 三问对应：—
  - 识别方法：深色、紫/红/黑配色
  - 常见组合：dark / dramatic / Victorian
