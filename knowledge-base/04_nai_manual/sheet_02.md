# NAI 手册 · 介质感

> 来源：00_input/nai_tag_manual.xlsx · 工作表「介质感」｜共 32 条｜数据集 v1.0.0

### 分组：▸ 数字类

- **digital art**  <sub>行 4</sub>
  - 中文含义：数字插画（通用）
  - 视觉识别特征：颜色平滑，无物理材质感
  - 典型风格代表：绝大多数现代二次元
  - 搭配建议：可省略，为默认值
- **clean digital art**  <sub>行 5</sub>
  - 中文含义：干净数字插画
  - 视觉识别特征：线条流畅，无杂质颗粒
  - 典型风格代表：商业插画风格
  - 搭配建议：配合clean lineart使用
### 分组：▸ 线稿/墨水类

- **ink**  <sub>行 7</sub>
  - 中文含义：墨线风格
  - 视觉识别特征：线条有浓淡变化，末端有锋
  - 典型风格代表：传统日本漫画
  - 搭配建议：配合monochrome或彩色均可
- **ink sketch**  <sub>行 8</sub>
  - 中文含义：墨水素描
  - 视觉识别特征：有笔触感，线条不完全均匀
  - 典型风格代表：速写/概念草稿感
  - 搭配建议：配合rough/sketch系tag
- **manga**  <sub>行 9</sub>
  - 中文含义：漫画风格
  - 视觉识别特征：网点、对话框、黑白线稿
  - 典型风格代表：少年/少女漫画
  - 搭配建议：通常搭配monochrome
- **crosshatching**  <sub>行 10</sub>
  - 中文含义：交叉排线
  - 视觉识别特征：用平行/交叉线表现明暗
  - 典型风格代表：西洋素描/铜版画感
  - 搭配建议：写实方向使用
- **brushwork**  <sub>行 11</sub>
  - 中文含义：笔刷质感
  - 视觉识别特征：可见的笔刷方向和压感变化
  - 典型风格代表：国风/书法感插画
  - 搭配建议：配合traditional media
- **calligraphy style**  <sub>行 12</sub>
  - 中文含义：书法风格
  - 视觉识别特征：笔势流动感，线条极有韵律
  - 典型风格代表：中国风/日本风
  - 搭配建议：配合ink
### 分组：▸ 水彩/水墨类

- **watercolor**  <sub>行 14</sub>
  - 中文含义：水彩
  - 视觉识别特征：颜色有晕染、水渍、纸张纹理
  - 典型风格代表：清新插画/儿童绘本感
  - 搭配建议：配合color bleed/wet media
- **wet on wet**  <sub>行 15</sub>
  - 中文含义：湿画法
  - 视觉识别特征：颜色互相渗透，边界模糊
  - 典型风格代表：水彩中最湿润的效果
  - 搭配建议：配合watercolor
- **color bleed**  <sub>行 16</sub>
  - 中文含义：颜色渗透
  - 视觉识别特征：颜色越出边界的效果
  - 典型风格代表：手作/温暖氛围
  - 搭配建议：配合watercolor/ink
- **sumi-e**  <sub>行 17</sub>
  - 中文含义：水墨画
  - 视觉识别特征：黑白墨色，留白大，笔墨简练
  - 典型风格代表：东亚传统绘画感
  - 搭配建议：配合monochrome
- **ink wash**  <sub>行 18</sub>
  - 中文含义：墨染
  - 视觉识别特征：墨色浓淡渐变，有水的流动感
  - 典型风格代表：中国风/禅意
  - 搭配建议：配合traditional media
### 分组：▸ 油画/厚涂类

- **oil painting**  <sub>行 20</sub>
  - 中文含义：油画
  - 视觉识别特征：颜色厚重，笔触明显，色彩浓郁
  - 典型风格代表：写实/古典画风
  - 搭配建议：配合impasto/painterly
- **impasto**  <sub>行 21</sub>
  - 中文含义：厚涂油画
  - 视觉识别特征：颜料明显堆叠，3D质感强
  - 典型风格代表：表现主义风格
  - 搭配建议：配合oil painting
- **painterly**  <sub>行 22</sub>
  - 中文含义：绘画感（通用）
  - 视觉识别特征：明显笔触，不依赖线条
  - 典型风格代表：广义厚涂/无线画风
  - 搭配建议：最常用的无线稿风格标记
- **acrylic paint**  <sub>行 23</sub>
  - 中文含义：丙烯颜料
  - 视觉识别特征：颜色鲜艳且哑光，干燥感
  - 典型风格代表：现代插画/街头艺术感
  - 搭配建议：配合bold colors
- **gouache**  <sub>行 24</sub>
  - 中文含义：不透明水彩/蛋彩
  - 视觉识别特征：颜色平整不透明，有哑光感
  - 典型风格代表：扁平插画/复古海报
  - 搭配建议：配合flat color/muted
### 分组：▸ 铅笔/色铅笔类

- **pencil drawing**  <sub>行 26</sub>
  - 中文含义：铅笔画
  - 视觉识别特征：灰色调，可见笔触方向，有纸张感
  - 典型风格代表：素描/草稿感
  - 搭配建议：配合sketch/rough
- **colored pencil**  <sub>行 27</sub>
  - 中文含义：彩色铅笔
  - 视觉识别特征：颜色略显干燥，有蜡质颗粒感
  - 典型风格代表：温暖手作感
  - 搭配建议：配合grainy texture
- **charcoal drawing**  <sub>行 28</sub>
  - 中文含义：木炭画
  - 视觉识别特征：深黑色，大面积暗部，有晕开感
  - 典型风格代表：写实素描/戏剧性强
  - 搭配建议：配合high contrast
- **pastel**  <sub>行 29</sub>
  - 中文含义：粉彩
  - 视觉识别特征：颜色柔和粉嫩，有粉末质感
  - 典型风格代表：少女风/梦幻感
  - 搭配建议：配合soft colors/dreamy
### 分组：▸ 印刷/复古类

- **risograph**  <sub>行 31</sub>
  - 中文含义：孔版印刷
  - 视觉识别特征：颜色分层，有印刷偏移感，半色调
  - 典型风格代表：独立出版/复古感
  - 搭配建议：配合limited palette
- **retro print**  <sub>行 32</sub>
  - 中文含义：复古印刷
  - 视觉识别特征：颜色褪色，有年代感
  - 典型风格代表：昭和/70年代感
  - 搭配建议：配合faded/muted
- **screen print**  <sub>行 33</sub>
  - 中文含义：丝网印刷
  - 视觉识别特征：颜色平实，层次分明，有套版感
  - 典型风格代表：波普艺术感
  - 搭配建议：配合flat color/bold
- **halftone**  <sub>行 34</sub>
  - 中文含义：半色调网点
  - 视觉识别特征：用小圆点构成图像（漫画常见）
  - 典型风格代表：漫画/波普风格
  - 搭配建议：配合manga/retro
### 分组：▸ 3D/特殊类

- **3d render**  <sub>行 36</sub>
  - 中文含义：3D渲染
  - 视觉识别特征：有景深、体积光、材质反射
  - 典型风格代表：游戏CG/概念设计
  - 搭配建议：配合volumetric lighting
- **cel shading 3d**  <sub>行 37</sub>
  - 中文含义：卡通3D渲染
  - 视觉识别特征：3D建模+动漫上色风格
  - 典型风格代表：现代3D动画感
  - 搭配建议：配合cel shading
- **low poly**  <sub>行 38</sub>
  - 中文含义：低多边形
  - 视觉识别特征：几何感强，三角面可见
  - 典型风格代表：极简/游戏资源风格
  - 搭配建议：配合geometric
- **pixel art**  <sub>行 39</sub>
  - 中文含义：像素画
  - 视觉识别特征：可见像素格子，复古游戏感
  - 典型风格代表：8-bit/16-bit游戏风
  - 搭配建议：配合retro/game style
- **ukiyo-e**  <sub>行 40</sub>
  - 中文含义：浮世绘
  - 视觉识别特征：日本传统木版画，平涂+线条+特定色系
  - 典型风格代表：江户时代日本画风
  - 搭配建议：配合woodblock/traditional
- **concept art**  <sub>行 41</sub>
  - 中文含义：概念设计图
  - 视觉识别特征：快速表达，有绘画感但偏设计
  - 典型风格代表：游戏/电影概念设计
  - 搭配建议：配合painterly/rough
